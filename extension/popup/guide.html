本插件呈现收录事实，不替你定级。收录库（CSSCI / CSCD / 北大核心 / 中科院分区）都是公开可查的第三方目录， 谁查都一样。校内认定级别（如山财 A1 – B1）则来自某个单位的自定口径 —— 因校而异、随文件更新而变， 换个学校就不适用。插件把两类信息都列出来，但始终标注来源：山财标签只代表山西财经大学的口径，不是普适的期刊分级。 最终认定以你所在单位的科研管理部门审核为准。

已知局限

  • 刊名写法不一致会匹配失败：少数期刊在不同平台写法不同（如「地理学报(北京)」与「地理学报」）。匹配失败时不显示标签，不报错 —— 这是刻意设计的，宁可不显示也不显示错。
  • CSSCI 集刊未收录（约 200 余种），集刊不会显示 CSSCI 标签。
  • Google 学术会把过长的刊名截断（如「Journal of Ver...」），截断后匹配不到，属正常现象。
  • 预警名单是历史累计（2020–2025），不代表该刊当下仍在名单内，请以官方最新公告为准。
  • 山财级别只对山西财经大学有意义，且是校内自定口径，不是普适分级。A1/A2 是办法里明文列入的目录；A3/A4/B1 属推定档 —— 由 CSSCI 扩展版、CSCD 扩展库等条件反推，仍需核验主办单位是否符合山西省教育厅「国家级学术刊物」条件，这一步必须人工做。所以内置数据里推定档可能与你手里的实际情况有出入：发现标错了，点标签直接在页面上改（升一级 / 降一级 / 五档直达），改动会被记住，也可一键还原成默认。最终认定以学校科研管理部门审核为准。

面板设置

设置项说明
启用标签显示总开关。关掉后所有页面不再注入任何标签，已打开的页面会立即恢复原样。
收录标签点开展开，勾选你关心的来源。上半部分是公开收录库（CSSCI / CSCD / 北大核心 / 中科院分区 / 预警名单），下半部分是校内认定（山财级别）—— 两类性质不同，面板里分组摆开。改动立刻生效，不需要刷新页面。级别不在这里单独设开关：山财级别只有这一个开关，A1 到 B1 五档都在它下面；要换档位请在网页上点那个标签，浮层里可以升一级、降一级或直接选档。
标签配色点开展开选色卡，六套内置 + 一套自定义（可逐个槽位取色或填 hex）。只影响标签外观，不改判定。
界面主题默认跟随系统：系统切深色模式，弹窗跟着切。也可以手动锁定浅色或深色。界面换色不影响网页上的标签。

使用方式

  1. 打开浏览器扩展管理页（Chrome / Edge 地址栏输入 chrome://extensions 或 edge://extensions）。
  2. 开启右上角「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择本文件夹（即含有 manifest.json 的 extension 目录）。
  4. 完成。打开知网或 Google 学术检索，刊名下方即出现标签。
