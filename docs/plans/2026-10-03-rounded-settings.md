# 工具栏完整圆角设置入口

原生工具栏弹窗的外层由浏览器绘制，内部 CSS 圆角无法移除其矩形背景。v1.0.2 取消 `action.default_popup`，由后台 `action.onClicked` 打开网页设置浮层，不再回退为原生弹窗。

已适配页面使用现有设置接收器。尚无接收器的普通页面，在用户点击图标后通过 `activeTab` 和 `scripting` 临时注入同一文件；设置脚本有幂等保护，不重复注册事件。自动刊名扫描范围不扩大。设置页面使用扩展源 iframe，外层为透明背景、24px 圆角与裁剪容器。

入口先做有超时的接收器探测，再决定是否注入脚本。未知消息不保留响应通道；即使旧页面仍有会挂起未知请求的旧监听器，探测也会在 750ms 后继续，不会无限等待。正式打开和转发消息也有超时上限。

扩展说明页加载设置接收器，使用按标签页 ID 路由的内部消息。后台仅接受自身设置 iframe 的就绪、尺寸与关闭消息；缺少 sender.tab 时，目标必须是本扩展页面。

浏览器受限页面或设置 iframe 初始化超时，打开带原标签页 ID 的独立设置页。用户主动取消初始化不另开设置页。设置仍保存在原来的本地存储中。

检查覆盖网页与说明页完整圆角、没有原生弹窗 target、六项收录开关、自定义色、主题、重新扫描、严格 CSP、动态注入、窄屏尺寸，以及页面移除 iframe 时的超时处理。自动测试调用工具栏实际使用的后台处理函数；不把后台函数调用等同于真实鼠标点击。


v1.3.0 统一包含山财级别，新增学校 WebVPN 自动注入（含嵌套页面）；设置消息指定顶层 frameId 0，避免多个页面副本重复打开面板。
